# アーキテクチャ（ブロック図・電源・電力見積もり）

版：draft-1（2026-11-01）。実測（measurement-procedure.md）の結果で更新する。

## 1. ブロック図

```
                ┌────────────── RF 部（シールド枠付き、ビアで囲う） ──────────────┐
 ANT-T (F) ─┬─ ESD ─ DCカット ─ [LNA SGL0622Z] ⇄ [SPDT AS179 ×2：バイパス] ─ 抵抗による4分配 ─┬→ T-in #0..#3
            │                                                                                    │
 ANT-S (F) ─┼─ ESD ─ DCカット ─ [LNA SGL0622Z] ⇄ [SPDT AS179 ×2：バイパス] ─ 抵抗による4分配 ─┼→ S-in #0..#3
            └─ (DNP) LNB 給電：15V ─ 電流制限 ─ チョーク                                         │
                                                                                                  ▼
   チューナー #n：CXD2858ER（水晶 16MHz）─ IF/IQ ─▶ 復調 #n：CXD2856ER（S3 版では CXD2857ER）（水晶 24MHz）
        ▲ I²C（復調 IC を経由するゲート、アドレス 0x60）           │ シリアル TS（CLK/DATA/VALID/SYNC）
        └──────────────────────────────────────────────────────────┤
                                                                   ▼
                          ┌──────────── iCE40HX4K-TQ144（HX8K と同じダイ） ────────────┐
   TS ×4 ───────────────▶ │ シリアル TS 受信 ×4 → 系統タグ付け → 多重化 → FIFO      │
   B-CAS（DNP）───────────│ ISO7816 UART（パターンのみ）                              │
   GPIO ──────────────────│ リセット ×4、LNA バイパス、LNB の有効化、LED          │
                          └───── GPIF II 同期スレーブ FIFO（16/32 ビット、〜100MHz）─┘
                                                     │            ▲ SPI（FX3 が FPGA に設定データを書き込む）
                                                     ▼            │
                     ┌──────────── FX3 CYUSB3014（BGA121、水晶 19.2MHz） ────────────┐
                     │ USB3 バルク転送 IN（TS）／ベンダーリクエスト（I²C、GPIO、FPGA の設定）│
                     │ I²C マスター ─ PCA9546A（4ch マルチプレクサ）─ 復調 #0..#3（各 0x64）│
                     │ 起動：USB 経由の起動か I²C EEPROM（24LC256）                         │
                     └──── USB-C（ブラケット側）／19 ピン USB3 ヘッダ（0Ω で選択、D-09）──┘
```

方式を決めた理由は次のとおり。

- **I²C は 4ch マルチプレクサで復調 IC ごとに分ける**
  - 参照ボードは 2 本のバスに 0x64 と 0x6c を割り当てている。こちらは 1 系統 1 バスにして、全部 0x64 で統一する
  - アドレス設定ピン（ストラップ）の違いで失敗する余地がなくなる
  - 1 系統を切り離しても他の系統に影響しない。これは D-06 で必要になったデバッグしやすさの対策でもある
- **FPGA の設定は FX3 が SPI で行う**
  - ホストが起動のたびにビットストリームを送るので、開発中は書き換えがすぐ済む
  - SPI フラッシュはパターンだけ用意する
- **FX3 のファームウェアも USB 経由で起動できる**ので、ホスト側のツールで書き換えて試す流れを短くできる

## 2. 参照ボードから分かっている数値

px4_drv の pxmlt_device.c と cxd2856er.c による（GPLv2）。

| 項目 | 値 |
|---|---|
| 復調 IC の I²C アドレス（7 ビット） | SLVT＝基準アドレス、SLVX＝基準アドレス＋2。参照ボードの基準アドレスは 0x64・0x65・0x6c |
| チューナーの I²C | 0x60。復調 IC の I²C ゲート（リピーター）の向こう側にある |
| 復調 IC の水晶 | 24MHz |
| チューナーの水晶 | 16MHz |
| TS 出力 | シリアル、188 バイト。ブリッジ側で sync バイトを 0x17〜0x57 に書き換えて系統を識別している |
| TS クロック | ゲート式。BS の 256QAM 系では「ハーフレート・高い周波数」の設定を使う。目安は 52Mbps の TS で 60〜80MHz 前後（**要実測**） |
| チューナーの LNA | 地上・衛星とも内蔵 LNA を有効にしている（ter.lna、sat.lna） |
| 電源投入の手順 | GPIO7 を Low（電源を有効化と推定）→ 80ms 待つ → GPIO2 を High（リセット解除と推定）→ 20ms 待つ |
| LNB の制御 | GPIO11 で全系統共通にオン・オフ |
| 地上側の周波数範囲 | 中心周波数 93〜767MHz（VHF1、CATV C13〜C63、UHF 13〜62ch）。帯域端で 90〜770MHz |
| 対応方式 | ISDB-T、ISDB-S、ISDB-C、J.83B |

## 3. 電源ツリー（案）

```
PCIe 12V（x1 では最大 0.5A＝6W）──┐
DC 入力 12V（基板上の端子、箱のときだけ）─────────────────┴─ OR（ショットキーダイオード）─ 12V_IN ─┬─ 降圧 DC-DC → 3.3V_SYS（〜2A）
                                                                         └─ (DNP) 昇圧 → 15.5V → LNB 用の電流制限スイッチ
PCIe 3.3V（最大 3A）──（0Ω/DNP で選択）── 3.3V_SYS へ合流（PCIe モードで 12V の負担を減らす場合）

3.3V_SYS ─ フェライトビーズ ─┬─ 低ノイズ LDO → チューナーとアナログ系（電圧は実測で決める。1.8V・3.3V 系を想定）×4（系統ごとに分ける）
                              ├─ LDO → 復調 IC のコア電圧（実測で決める。1.2V 前後を想定）×4（系統ごと、EN 付き）
                              ├─ LDO 1.2V → iCE40 コア ／ LDO 1.2V → FX3 コア
                              └─ 3.3V → FX3・FPGA の I/O、LNA、I²C マルチプレクサ
```

**注意点**：PCIe x1 カードの電力上限は 12V が 0.5A（6W）、全体で 10W。ロープロファイルは 25W への拡張が認められていない。D-30 により、PCIe で使うときは LNB 給電をせず、補助電源もつけない。3.3V 系の負荷はスロットの 3.3V から取って、12V 側の負担を減らす。参考までに、LNB に給電する場合の選択肢は次のとおり。

- 3.3V 系の負荷をスロットの 3.3V から取る
- DC ジャックから補助給電する

## 4. 電力見積もり（暫定）

| ブロック | 個数 | 1 個あたり | 合計 | 根拠 |
|---|---|---|---|---|
| CXD2858ER（チューナー） | 4 | 0.4〜0.6W | 1.6〜2.4W | 推定。**実測で更新する** |
| CXD2856ER（復調） | 4 | 0.25〜0.4W | 1.0〜1.6W | 推定。**実測で更新する** |
| SGL0622Z（LNA） | 2 | 35mW | 0.07W | データシート（3.3V×10.5mA） |
| FX3 | 1 | 0.4〜0.6W | 0.5W | 推定（USB3 で転送中） |
| iCE40HX4K | 1 | 〜0.1W | 0.1W | 推定 |
| DC-DC と LDO の損失 | — | — | 0.8〜1.2W | 推定 |
| **小計（LNB なし）** | | | **約 4〜6W** | PCIe の上限 10W に収まる |
| LNB 給電（15V、最大 0.27A） | — | — | 最大 4W＋変換損失で約 4.7W | アンテナ側の負荷による |
| **合計（LNB あり）** | | | **約 9〜11W** | **上限を超えうる**。補助給電が前提 |

参照ボード（ロープロファイルの x1 カードに 4 系統と LNB 給電）が実際に動いているので、Sony IC の実際の消費電力はこの推定より小さい可能性が高い。measurement-procedure.md の手順で、参照ボード全体の消費電力を測って確かめる。
