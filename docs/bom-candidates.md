# 部品候補表（BOM の叩き台）

調査日：2026-11-01。在庫と価格は JLCPCB の部品ライブラリ API で調べた値（1 個買いの単価）で、すぐに変わる。
種別の「基本」は JLCPCB の Basic 部品（追加料金なし）、「拡張」は Extended 部品（部品の種類ごとに追加料金がかかる）。
「支給」は JLCPCB に部品を送って実装してもらうもの。
