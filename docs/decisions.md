# 決定事項ログ

初期ヒアリング（2026-11-01）で確定した方針。変更時はこのファイルに追記し、理由を残す。

| # | 項目 | 決定 | 備考 |
|---|---|---|---|
| D-01 | 目的 | 自分用の録画環境が主。頒布・販売にも耐える設計にする | 線引きは research.md §9 |
| D-02 | BS4K の目標 | ISDB-S3 の復調と TLV 出力まで。ACAS による復号は対象外 | |

| D-04 | 復調・チューナー IC | Sony 製をブローカーから調達（CXD2856ER / CXD2858ER） | 偽物や再刻印品を前提に、受入検査をする |
| D-05 | S3 用チップ | v1 では調達しない。ジャンクの 4K 機器から取り外して入手する | CXD2856ER と CXD2857ER の載せ替えを前提に基板パターンを作る（ピン互換は未検証） |
| D-06 | 系統数 | 4 系統。最初から 4 系統の基板を作る | 1 系統の評価基板は作らない。代わりに系統ごとに切り離せる設計にする（R-03） |
| D-07 | ホスト接続 | **改訂（2026-11-01）**：iCE40HX4K-TQ144 ＋ FX3（CYUSB3014）。当初は iCE40HX8K（TQ144）＋ FT601 だった | 改訂の理由は 3 つ。HX8K には TQ144 版がない（HX4K-TQ144 の中身は HX8K と同じダイ）。FT601 はドライバのソースが非公開で、GPL での公開（D-19）と衝突する。BGA は JLCPCB の実装で問題にならない |
| D-08 | 形状と電源 | PCIe ロープロファイル形状と外付け箱の両方に対応 | PCIe は電源だけを使う（補助電源なし、10W 以内）。箱では基板上の DC 入力端子に 12V を入れる（D-30） |
| D-09 | USB コネクタ | ブラケット側の USB-C とマザーボード内部の USB3 ヘッダの両方。どちらか一方を実装する | SuperSpeed 線は分岐させず、0Ω 抵抗で選ぶ |
| D-10 | ソフトウェア | **改訂（2026-11-01）**：Linux、Windows、macOS。Linux を先に作る | libusb 系のユーザー空間ドライバ。recpt1 互換、その後 BonDriver。FX3 と libusb の構成なので macOS にも対応できる |
| D-11 | 実装 | JLCPCB の部品実装サービスを使い、Sony IC は支給または後付け | |
| D-12 | 予算と測定 | 5 万円程度。測定器は SDR（RTL-SDR）で代用 | 復調 IC が出す C/N・BER・信号強度も測定に使う |
| D-13 | B-CAS カードリーダー | 基板パターンだけ用意し、部品は実装しない | 復号機能は基板にもドライバにも持たせない |
| D-14 | アンテナ入力 | 地上用と衛星用の 2 端子（F 型） | |
| D-15 | アンテナ給電 | LNB への 15V 給電回路はパターンだけ用意し、部品は実装しない | |
| D-16 | 受信帯域 | 地デジ、BS/110 度 CS（右旋）、CATV（パススルーと ISDB-C）。左旋は RF 経路だけ確保 | |
| D-17 | LNA（受信アンプ） | バイパスできる LNA を載せる | |
| D-18 | CAD | KiCad を使い、JLCPCB 向けプラグインで出力する | |
| D-19 | 公開 | オープンハードウェアとして公開。基板は CERN-OHL-S-2.0、ホスト側と FPGA は GPL-2.0-only、FX3 ファームは MIT（D-29） | px4_drv と tbs6812_drv が GPL-2.0-only なのに合わせる |
| D-20 | 品番 | OTR-4TS3-U1 | Open Tuner Receiver／4 系統／地上・衛星（S3 対応）／USB／第 1 版 |
| D-21 | Sony IC の調達 | 少量をブローカーから買い、検収してから追加購入する | 検収では I²C でチップ ID を読み、参照ボードと同じように動くかを確かめる |
| D-22 | 実測の道具 | テスターと接写撮影 | 手順は measurement-procedure.md |
| D-23 | 設計前の準備 | ブロック図と電力見積もり、実測手順書、部品候補表、先行検証計画を作る | architecture.md ／ measurement-procedure.md ／ bom-candidates.md ／ preverification-plan.md |
| D-24 | I²C の構成 | FX3 の I²C から TCA9546A で 4 本に分け、復調 IC はすべて 0x64 にする | アドレス設定のミスをなくし、系統ごとに切り離せるようにする（D-06 への対策） |
| D-25 | FPGA の設定 | FX3 が起動時に SPI で FPGA に設定データを書き込む。フラッシュはパターンのみ | 開発中の書き換えが速い |
| D-26 | RF 前段 | SGL0622Z（LNA）、AS179 によるバイパス、抵抗による 4 分配。地上用と衛星用で 1 組ずつ | 直流から 3.2GHz まで平坦で、特殊な部品がいらない |
| D-27 | 検証用の PC | PCIe スロット付きの Linux 機と Windows 機の両方がある | 段階 S0（参照ボードで基準データを取る）は Linux から始める |
| D-28 | 購入 | 今買うのは PCIe 延長ライザー（約 1,000 円）だけ。評価ボードと Sony IC のサンプルは保留 | 段階 S1・S3・S4 は評価ボードを買うまで保留。R-11 を参照 |
