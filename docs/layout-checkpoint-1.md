# 配置の確認（1 回目の節目、D-51）

対象は第 1 段階の部品（FX3、FPGA、電源、USB、I²C、RF 前段）の仮配置と、基板の外形。受信部（4 系統）は、参照ボードの実測を待つあいだ枠だけを確保している。

## 開き方

```
open hw/kicad/otr-4ts3-u1.kicad_pro
```

PCB エディタで開く。3D ビューア（Alt+3）で表から見ると、全体がつかみやすい。

レイヤーは次のものを表示しておく。

| レイヤー | 内容 |
|---|---|
| User.Drawings | 受信部の枠（RX0〜RX3）、ねじの頭の範囲 |
| User.Comments | 部品群ごとの配置範囲 |
| B.Fab | 裏面の B-CAS カードの範囲 |
| F.Fab | 部品番号 |

部品番号は、密集した部品に重ならないよう、シルクではなく F.Fab に置いている。

## 作り直し方

基板は生成物なので、手で動かしても次の生成で上書きされる。直したい点は、ファイルではなく言葉で伝えてほしい。

```
python3 hw/gen/design.py                     # 回路図とネットリスト（先に必要）
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 hw/gen/pcbgen.py
```

## 見てほしい点

1. **ブラケットの端子の並び（D-62）**：上から ANT-S（J6）、ANT-T（J5）、USB-C（J3）。
2. **F 型端子の出方**：端子の本体の前面を、ブラケットの内側の面に当てる位置にしている。ねじ部のうちブラケットの外に出るのは約 7mm。
   - メーカーの図面は寸法の読み取りに曖昧さがある。実物（JLC C2979612）が手に入ったら合わせる。
3. **USB-C の出方**：受け口の前面は基板の端から 0.17mm 出るだけで、ブラケットの外面より約 1.7mm 奥になる。プラグの根元がブラケットの穴に入るので、穴はプラグの外形（約 12.4×6.5mm）より大きく開ける。
4. **ねじ穴（H1・H2）**：CEM の寸法で置いた。買うブラケットの足の穴に合っているか、実物で確かめてほしい。写真から見積もった参照ボードの間隔（約 57mm）は、こちら（53.9mm）より広い。写真の歪みの可能性が高い。
5. **DC 入力（J2）と内部 USB3 ヘッダ（J4、DNP）**：奥の端に置いた。箱で使うときの線の取り回しに困らないか。
6. **長さ 120mm に収まるか（D-52）**：受信部 1 系統あたりに使えるのは約 22×27mm。参照ボードの 1 系統（チューナーと復調の組）は写真で約 20×28mm なので、ぎりぎり収まる見込み。実測後に受信部を描いた時点で、延長が要るかを判断する。

## 外形の根拠（D-64）

| 項目 | 値 | 出典 |
|---|---|---|
| 端子の下端から上辺まで | 68.90mm | CEM（ロープロファイル） |
| 肩（端子の脇の基板の下辺） | 12.75mm | ULX4M-PCIe-IO の雛形。安全側。実測で見直す |
| ブラケット側の端 | B1 の端子から 45.15mm | 同上 |
| ねじ穴 | 端子の下端から 9.35mm と 63.25mm、端から 7.5mm | 同上（ブラケットの足は裏面） |
| 部品の高さの上限 | 表 14.47mm、裏 2.67mm | 同上 |

## わかっている課題（配線の段階で扱う）

- J3 のシルクが基板の端からはみ出す（コネクタが端に掛かる設計のため）。製造上は問題ない。
- 配置は部品群ごとに詰めただけで、デカップリングコンデンサをピンの近くに寄せる調整はまだしていない。
- B-CAS のコネクタの品番は未定（D-63）。裏面の範囲だけを確保している。
