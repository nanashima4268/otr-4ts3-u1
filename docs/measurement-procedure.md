# 参照ボード（DTV02A-4TS-P）の実測手順書

目的：データシートが公開されていない CXD2856ER と CXD2858ER の、電源電圧、ピンの役割、RF 経路を、参照ボードから読み取る。
道具：テスター（マルチメーター）、スマホのマクロ撮影かルーペ（D-12）。
結果は `docs/reference/measurements.md` に、この文書のテーブルの形で記録する。

## 0. 準備と注意

- **静電気に注意する**：作業前に金属に触れて放電し、乾燥した日は避ける。
- **短絡に注意する**：Sony IC は 48 ピン、0.5mm ピッチの QFN。テスター棒で隣のピンとショートさせやすい。
  - 通電中は IC のピンに直接当てない
  - 代わりに、近くのパスコン（0402 サイズ程度の小さなコンデンサ）の両端で測る
- **ピン番号の数え方**：IC の刻印を正しい向きに置き、丸い印のある角が 1 番ピン。そこから反時計回りに 1〜48 番（1 辺 12 本）。
- **あると便利な道具**（任意、約 1,000 円）：PCIe x1 延長ライザー（マイニング用の USB ケーブル型）。カードを PC ケースの外に出して作業できる。

## 0-1. 停止の段取り（参照ボードは本番の pve-old に挿さっている）

参照ボードは本番の録画サーバー pve-old（VM110 vm-rec）に挿さっている。カードを外すには pve-old 自体を止める必要がある。
止めている間は、pve-old 上のゲストもすべて止まる（edge、hato、minecraft、vm-lab など）。さらに、**起動ディスクの NVMe は SMART で FAILED**で、過去に再起動に失敗した記録がある。
このリスクを承知のうえで止めると決めた（D-35）。

1. **時間帯を選ぶ**：EDCB の予約録画がない時間帯にする（`127.0.0.1:5510/api/EnumReserveInfo` で確認）。撮影と導通測定だけなら、カードを外してから戻すまで 1 時間程度を見込む。
2. **バックアップを確かめる**：homelab-infra の pve-old.md にある予備系の複製（zfs send）が最新か確認する。VM140 と VM200 は予備系にないので、必要なら先に退避する。
3. **ゲストを順に停止してから、ホストを停止する**。
4. **カードを外して作業する**：§1（撮影）と §2（導通測定）は通電せずにできる。§3 と §4（通電測定）では、カードをライザー経由で外に出したまま pve-old を起動するか、短時間だけケースを開けたまま起動して測る。
5. **元に戻して確かめる**：カードを戻して起動する。vm-rec で `/dev/isdb6014video0-3` ができていること、Mirakurun で 4 チューナーとも `isAvailable` が true になっていることを確認する。次の予約録画が成功するところまで見届ける。

## 1. 接写撮影（通電しない）

光を斜めから当てると刻印が読みやすい。刻印が薄い場合は、無水エタノールで拭いてから撮る。
表面・裏面それぞれで、基板全体を 1 枚撮ってから部品ごとに撮る。

| # | 対象（シルクの番号） | 場所 | 知りたいこと |
|---|---|---|---|
| P1 | U13（刻印のない QFN） | 表面の中央上 | 4 個目の CXD2858ER か、別の IC か |
| P2 | 左上の QFN（Y4 の近く。番号は撮影時にシルクで確かめる） | 表面 | 型番。CXD2858ER か RF 前段の IC の可能性がある |
| P3 | U15、U16、U18、U19 | 表面の F 型コネクタ付近 | RF 前段（LNA、分配器、スイッチ）の型番 |
| P4 | U5（SOT-23-5 の小さい IC）、L44〜L50 | 表面の下側 F 型コネクタ付近 | LNB 給電の回路 |
| P5 | U21、D3、Q4、Q5 | 表面の左上 | 電源回路（LNB 用の昇圧か） |
| P6 | U14（刻印のない QFN、USB ヘッダの横） | 裏面 | 型番。カードリーダー制御か USB ハブの可能性がある |
| P7 | SOIC-8（U1 付近） | 裏面の右端 | EEPROM か SPI フラッシュか |
| P8 | L2、L3 の周辺と U1、U2 | 裏面 | DC-DC コンバータの IC の型番。出力電圧の手がかりになる |
| P9 | 各 Sony IC の周りのパスコン群 | 両面 | 電源ピンとパスコンの位置関係 |
| P10 | 水晶 Y1〜Y12 | 両面 | 周波数の刻印（16.000、24.000 など） |

## 2. 導通測定（通電しない）

テスターを導通モード（ブザー）か抵抗モードにする。グランドは F 型コネクタの外側の金属や、ブラケットのネジで取る。

### 2-1. 電源ネットのグループ分け

1. 各 Sony IC の周りにあるパスコンの、グランドでない側の電極を順に測る。どの電源 IC の出力とつながっているかを調べる。
2. 同じ電源につながっているパスコンを、同じグループとして記録する。

| IC（Uxx） | パスコン | つながっている電源（電源 IC やコイルの番号） | グループ名 |
|---|---|---|---|
| U8（CXD2856ER） | C?? | | |
| U7（CXD2858ER） | C?? | | |

### 2-2. Sony IC のピンの接続先

0.5mm ピッチなので、細い針状の測定棒（先端 0.3mm 程度）を使うか、ピンの外側に出ている根元に当てる。

| IC | ピン番号 | グランド | 電源グループ | 接続先（IT9305E のピン、水晶、他の IC など） | 推定される役割 |
|---|---|---|---|---|---|
| U8 | 1 | | | | |

役割の手がかりは次のとおり。

- **水晶**：両端が IC のどのピンにつながるか（XTAL_IN と XTAL_OUT）
- **IT9305E への 4 本**：TS の CLK、DATA、VALID、SYNC
- **I²C（SDA、SCL）**：IT9305E とつながり、プルアップ抵抗が付いている
- **アドレス設定ピン**：グランドか電源に直結されているピン。系統ごとに違うはず（0x64 と 0x6c の違い）
- **チューナーの I²C**：CXD2858ER の I²C 2 本が CXD2856ER のどのピンに行くか（ゲート用の出力）
- **IQ・IF 信号**：CXD2858ER と CXD2856ER の間を直結しているピンの組。差動ペアが 2 組あると推定

### 2-3. RF 経路

F 型コネクタの芯線から、チューナー IC の RF 入力ピンまでの経路をたどる。

- コンデンサは直流を通さないので、導通が途切れたら写真で配線を追う
- コイルと 0Ω 抵抗は導通する
- 地上側と衛星側が、それぞれどのピンに入るかを記録する

## 3. 通電測定（DC 電圧）

PC に挿して px4_drv（または Windows の公式ドライバ）で受信できる状態にし、2 つの状態で測る。

- **待機中**：ドライバは読み込まれているが、受信していない
- **受信中**：TVTest や recpt1 で 1 系統以上を受信している

px4_drv は、受信を始めたときにボード全体の電源を入れる（GPIO7 → GPIO2）。待機中は Sony IC の電源が切れている可能性がある。

## 4. 消費電力（任意）

ライザーを使う場合、ライザーの電源ケーブル（12V）にテスターを直列に入れ、電流レンジで測る。

- 測定状態：待機中、地デジ 1 系統、4 系統、BS 4 系統、BS 4 系統＋LNB 給電
- **注意**：テスターの電流レンジ（10A 端子）に正しく挿し替えること。挿し間違えるとヒューズが飛ぶか、ショートする
