# GPIF II configuration (D-41)

`cyfxgpif2config.h` configures the FX3 GPIF II as a 16-bit synchronous slave FIFO, the FPGA side of D-39. The firmware (`fx3/fw/otr_stream.c`) includes it directly. It is generated by GPIF II Designer 1.0.1198.2 (Windows only) from the project in `otr_sfifo16.cydsn/` and must not be edited by hand.

## How it was made (2026-11-01)

1. The project started as a copy of the `sync_slave_fifo_2bit` design that ships with GPIF II Designer (FX3 SDK 1.3.5).
2. The only change is FLAGA, connected to Thread_0_DMA_Ready.
3. The header was built with the Designer's console tool (`cyconsoletool.exe build`). The build succeeded and passed the tool's consistency check.
4. The tool warns that it removes SLWR/PKTEND terms from the IDLE and DSS_STATE transitions to build "mirror states". This is the template's normal behaviour.

| Setting | Value |
|---|---|
| Interface | Slave, synchronous, external clock (PCLK from the FPGA, 50 MHz), positive edge |
| Endianness | Little endian (first byte on DQ[7:0]) |
| Data bus | 16 bit, not address/data multiplexed, 2 address pins |
| FLAGA (CTL4, GPIO21) | Thread 0 DMA ready: 1 = a buffer is free, 0 = full or no buffer. Initial value low |
| FLAGB (CTL5, GPIO22) | Current-thread DMA ready, as in the template. **Not used** by the FPGA or the firmware |

The Designer's `documentation/` folder (a datasheet written by Cypress, with its images) and the build log are deliberately not committed. They are regenerated when the project is opened or built.

## Checks on import

Compared with the SDK's sync slave FIFO example in 16-bit mode (`cyfxgpif_syncsf.h`, `CY_FX_SLFIFO_GPIF_16_32BIT_CONF_SELECT 0`), the state machine (7 states), transition functions, waveform table, waveform positions, and ALPHA_RESET are identical. Only the control-pin registers differ:

| Register | Generated header | SDK example |
|---|---|---|
| CTRL_BUS_SELECT[4] (FLAGA) | 0x10 thread 0 DMA ready | Same |
| CTRL_BUS_SELECT[5] (FLAGB) | 0x18 current thread DMA ready | 0x14 thread 0 watermark |
| CTRL_BUS_SELECT[6], [8] | Unused | Thread 3 flags |
| CTRL_BUS_POLARITY / DIRECTION / DEFAULT | Only the bits for CTL4/CTL5 are set | Also the bits for CTL6/CTL8 |

The polarity of FLAGA and of the input strobes (SLCS#, SLWR#, SLOE#, SLRD#, PKTEND#) is the same as in the SDK example. The FPGA model (`fpga/sim/fx3_sfifo_model.v`) assumes FLAGA high = ready, so the two agree.

The header contains no Cypress copyright notice (D-37). The firmware builds with it under `-Wall -Werror`.
