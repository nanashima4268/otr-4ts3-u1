# host

The host software lives in a separate repository: https://github.com/nanashima4268/otr-userland (D-44).
It is a sibling of the Khronos31 `*-userland` family: a user-space daemon `otrd` with `otr-ts`/`otrctl` clients, built on dtv-userland-core and reusing the px4-userland CXD2856ER/CXD2858ER code.
